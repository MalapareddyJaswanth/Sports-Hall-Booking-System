# Technology Stack

The Sports Hall Booking System is built using the following technologies:

## Front-End Frameworks (Service Portal)
*   **HTML5 & CSS3/SCSS**: Provides layout and custom responsive styling (dark gradients, glassmorphism, responsive grid).
*   **AngularJS (v1.x)**: Handles client-side controller logic, scope states, and AJAX server calls.
*   **Bootstrap 3**: Embedded grid layout framework for Service Portal widgets.
*   **FontAwesome**: Integrated icon sets for facility cards and user dashboards.

---

## Back-End & Platform (ServiceNow Scoped App)
*   **App Engine Studio**: Scoped application structure (`x_2112820_sports_2`).
*   **GlideRecord Scripting**: Backend Javascript queries used in Server Scripts, Business Rules, Scheduled Jobs, and Email Scripts.
*   **Flow Designer**: Visual approval workflows.
*   **Scheduled Script Execution**: Platform scheduler for daily automation cleanup.
*   **Access Control Lists (ACLs)**: Security rules ensuring data segregation.
