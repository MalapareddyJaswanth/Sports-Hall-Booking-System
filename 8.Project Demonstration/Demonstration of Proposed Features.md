# Demonstration of Proposed Features

This document outlines the script and structure of the project demo.

## Demo Script Outline:
1.  **Introduction (Natta Hemasree)**: Project overview, objectives, and roles.
2.  **Facility Selection & Portal View (Shaik Asmin)**: Showcasing the Portal UI design, facility cards, and responsive CSS grids.
3.  **Reservation Submission (Jaswanth Malapareddy)**: Creating a pending reservation and showing database transactions.
4.  **Double Booking Block Demo (Veerla Purna)**: Attempting a duplicate reservation to show how the Business Rule aborts the request.
5.  **Flow Approval & Email (Vishwanth Kurapati)**: Approving the booking and showing the dynamic email notification sent to the student.
6.  **Auto-Rejection of Competitors**: Showing how concurrent requests are rejected automatically.
